Um espaço pessoal para organizar os estudos de programação e praticar lógica, memória e atenção no navegador.

## Recursos

- Anotações para registrar e consultar resumos e ideias.
- Tarefas organizadas entre pendentes e concluídas.
- 10 jogos, incluindo xadrez, memória, matemática e exercícios de inglês.
- 6 desafios de programação com explicações das soluções.

## Tecnologias

HTML, CSS e JavaScript. O mapa de países utiliza D3.js e TopoJSON.

## Executar localmente

Com Python 3 instalado, abra o terminal na pasta do projeto e execute:

```bash
python3 -m http.server 8000
```

Acesse [localhost:8000](http://localhost:8000). O mapa de países requer conexão com a internet para carregar suas dependências e dados.

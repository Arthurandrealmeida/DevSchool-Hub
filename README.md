# 📘 DevSchool Hub

DevSchool Hub é uma plataforma web pessoal criada para centralizar meus estudos de programação, lógica e desenvolvimento web em um único ambiente.

O objetivo do projeto é reunir ferramentas, mini-apps e recursos interativos que eu utilizo no dia a dia da escola e dos estudos técnicos, funcionando como um "hub" pessoal de aprendizado.

🔗 Acesse o projeto:  
https://arthurandrealmeida.github.io/DevSchool-Hub/index.html

---

## 🎯 Objetivo do Projeto

Durante meus estudos percebi que eu utilizava vários sites e ferramentas diferentes para aprender programação e treinar lógica.

Criei o DevSchool Hub como um espaço único onde posso:
- Organizar conteúdos de estudo
- Praticar conceitos de programação
- Criar pequenos projetos educacionais
- Experimentar ideias de interface e interação

Este projeto funciona como meu laboratório pessoal de front-end e produtividade.

## ⚙️ Funcionalidades

O projeto reúne múltiplas páginas e ferramentas educacionais, incluindo:

- Área central com acesso rápido a recursos de estudo
- Mini aplicações interativas
- Jogos e desafios simples de lógica
- Interface responsiva para desktop e mobile
- Navegação entre múltiplos módulos dentro de um único projeto

## 🧠 Aprendizados Técnicos

Durante o desenvolvimento deste projeto trabalhei principalmente com:

- Organização de múltiplas páginas em um único projeto web
- Manipulação de DOM com JavaScript puro
- Estruturação e modularização de arquivos
- Responsividade com CSS
- Deploy automático utilizando GitHub Pages

Este projeto é continuamente atualizado conforme avanço nos estudos.
